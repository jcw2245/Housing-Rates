# Housing-Rates
 
This project I focused on graphics and trying to find a new and unique way to do this assignment. I used multiple pieces of data to piece together this story, as I have never done a housing piece before and reached out to some sources. I then did some work with graphics.

I wanted to do a scrollytelling piece with ai2HTML graphics. I created the graphics at first with houses trying to build a nieghborhood. I do not have the tools to professionally draw so I used my graphic design tools. I then chose different graphics from the first one, as the first one did not go well with the topic. I created these graphics in two different sizes for both desktop and mobile.

After this I had to focus on the coding, which took the most time. It kept messing up the scorllytelling, so I had to change my first plan of using the other graphic and point that I had to go with the scrollytelling because it was not working with the zooming function. I finally got it to work and kept it with two of the original points.

If I had more time, I would have used the third graphic and created more clear or realistic graphics (but this also depended on what I had available to use). I also would have made certain parts of them react and have minimal motion. I would have also done more interviews. 

My inspiration were the map pieces that were shown in class that would zoom in and zoom out to different places. I found a piece like it to be my inspiration for this assignment which is: https://www.nytimes.com/interactive/2023/10/29/upshot/new-york-neighborhood-guide.html
